Nangi Mugira's project portfolio covers the full data workflow: collecting and cleaning raw data, building and evaluating machine learning models, deploying them live, and 

turning the results into dashboards and APIs that other people can use. The projects range from financial services and customer analytics to healthcare and language technology.

Bank Term Deposit Prediction (Deployed). Nangi built an end-to-end predictive model to identify which bank customers are likely to subscribe to a term deposit, working with a dataset of about 45,000 customer records. 

The work started with data cleaning and exploratory data analysis to find customer trends. Nangi then did feature engineering, trained and compared ensemble methods, and validated the results, reaching a ROC-AUC of about 0.91. Nangi then deployed the model live, carrying it through the full develop, test and maintain cycle that production data science requires. The project shows how a model can help a business target the right customers and use marketing resources more efficiently. Tools: Python, pandas, NumPy, scikit-learn, Matplotlib, Jupyter, Git/GitHub.

Swahili Audio Classification (Speech Recognition). Nangi developed a machine learning system that converts Swahili audio into written text. The project addresses a real gap: low-resource languages like Swahili have far fewer speech tools than English. Nangi processed the audio data, used a ResNet-18 convolutional neural network for classification, and connected the model to a web backend so it could be used through an application. The project shows Nangi's ability to work with unstructured data, apply deep learning, and connect a model to a working system. Tools: Python, neural networks (ResNet-18), audio processing, web backend integration.

Caretaker Reports. Nangi built a reporting and analytics system that tracks the operational performance of caretaker services. The system pulls in data from JSON, Excel and CSV sources, cleans it and standardizes it into a consistent structure. Nangi exposed the data through Flask APIs so it could be accessed reliably for different analysis needs, then built dashboards to support operational decisions. The project mirrors the reporting-pipeline work Nangi has done professionally. Tools: Python, pandas, SQL, Flask, REST APIs, data visualization tools.

Customer Segmentation & Recommendation. Nangi built collaborative-filtering models to segment customers by behavior and generate personalized recommendations, using the KNNBaseline and SVD algorithms. Nangi compared model performance to pick the strongest approach. The project applies directly to customer analytics, personalization and revenue management. Tools: Python, scikit-learn, collaborative filtering (KNNBaseline, SVD), Jupyter.

Coronary Heart Disease Prediction. Nangi built a model to estimate a person's likelihood of developing coronary heart disease within 10 years, with the goal of supporting early, personalized risk assessment. The work included exploratory analysis of clinical risk factors, model training and evaluation, and visualizations to explain which factors drive risk. Tools: Python, pandas, scikit-learn, Matplotlib.
